What it does

Most people run their week across a dozen apps, each with its own account and its own server. In Nexus a task, an exam and an expiring passport share one calendar, one search box and one set of reminders.

Tasks and calendar

To-dos with priorities, subtasks, recurrence and dependencies, as a list, a board or a calendar. Month, week, day and agenda views, with events you drag and resize.

Notes and a private vault

Notes with folders, tags, backlinks and version history. Private notes are encrypted so only you can read them, with a Recovery Kit of their own.

Study

Exam countdowns, spaced-repetition flashcards, typeset maths and Anki import, plus a planner that books study time before each exam and re-plans when you fall behind.

Life admin

Accounts, budgets and subscriptions, with every currency kept separate. Habits with forgiving streaks, and reminders weeks before your ID, passport or registration expires.

Food and training

426 foods with the source of every number, 230 exercises, routines and personal records, and an energy estimate measured from your own weight trend.

Tools and a canvas

Calculators, eighteen professional toolkits you opt into, an infinite canvas with live cards, and an electronics bench that writes the Arduino or ROS 2 code your wiring implies.

How it works

Your privacy in Nexus comes from how the code is built, not from a promise in a policy.

  1. Your computer is the server

    Everything lives in one encrypted SQLite database on your computer that opens only with your passcode or your Recovery Kit. Attachments are encrypted with AES-256-GCM.

  2. No way out to the network

    The local app has no code path that reaches the network, and CI enforces it. Sync between devices is being built end-to-end encrypted, and will stay off unless you turn it on.

  3. Only what you need

    A short setup asks about your week and switches on the modules that fit. Personal and business profiles keep their data apart, and several accounts can share one computer.

  4. A locked-down interface

    The interface runs sandboxed and never touches the database. It asks the main process through an allowlist of typed requests, each validated field by field, and every query binds its values.

  5. Yours to take away

    Export everything into one sealed archive and restore it anywhere, or merge another archive into yours. Encrypted backups can run on a schedule.

Tested, and honest about limits

How it's verified

  • Vitest in every package, with data and store logic written test-first.
  • 26 static checks run in CI beside the build, type checks, lint and tests, along with a secret scan and a dependency audit.
  • A smoke test launches the built app, opens every page under the production content security policy and exercises the real database.

What it can't do yet

  • Other languages. The interface is in Serbian and English; no other language ships yet.
  • Sync and the web app. Both are paused until the desktop app is finished. The desktop app is complete without them.
  • macOS. Installers are built for Windows and Linux only, and code signing for the Windows installer is paused for now. The source is open, so anyone can check what it does.

Questions

Is Nexus free?

Yes. Nexus is free and open source under the Apache License 2.0. It has no ads, no online account and no telemetry.

Does Nexus need the internet?

No. Every feature works with the network off. The local app has no code path that reaches the network, and a CI check enforces it.

Is Nexus available in English?

Yes. The interface ships in Serbian and English: on first run it follows the system language (Serbian when the system locale is sr*, English otherwise) and remembers the choice, which you can change in Settings. The code and documentation are in English.

Which platforms does Nexus run on?

Windows 10 and 11 (a per-user installer) and Linux (an AppImage, a tarball and a Gentoo ebuild), all x64.

How is my data protected?

Everything is stored in one encrypted database on your computer that opens only with your passcode or your Recovery Kit, and attachments are encrypted with AES-256-GCM. Private notes are encrypted so that only you can read them.

Can I take my data with me?

Yes. Nexus exports everything into a single sealed archive that you can restore later, on the same computer or another one, or merge into an existing profile. Encrypted backups can also run on a schedule.

Get Nexus

A per-user installer on Windows, or an AppImage on Linux. Uninstalling keeps your data unless you choose to remove it.
