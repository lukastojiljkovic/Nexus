# PRD 01 — Onboarding (removed)

**Status:** removed in Nexus 3.0 on 2026-10-24.

Nexus no longer asks a first-run questionnaire. Account creation produces a
named personal profile and opens the shell directly. Every registered module is
visible on a fresh install; the user can hide or reorder modules later in
Settings.

The former ONB requirements remain in product history at
[`../log/superseded-onboarding-prd.md`](../log/superseded-onboarding-prd.md).
