It is the file the reader's tests open for the parts that only a real,
third-party-written ZIM can prove: the 80-byte header, the terminated MIME list,
the URL and title pointer lists, five redirect entries (including
`A/Main_Page.html`, which redirects to the Belarusian main page), 118 entries
over the `-`, `A`, `I` and `M` namespaces, the main page, a title index of 118
offsets, and an uncompressed cluster whose 34 blobs are all PNGs.

It is also, deliberately, a **format 5.0** file: its first cluster is
LZMA2/XZ-compressed, which this reader refuses by name (`ZimError` with the
problem `compression`). That refusal is asserted rather than worked around —
see ADR-098 for why no LZMA decoder is shipped.

Its own MD5 trailer is real and verifies:
`2fb62a7110deffd3b192d922dffa02c1` (the MD5 of its first 152 849 bytes, which is
what `ZimReader.checksumMatches()` recomputes).

Nothing in this folder is generated by Nexus, and nothing here is written to at
runtime: the reader opens fixtures read-only, exactly as it opens a pack the
user downloaded.
