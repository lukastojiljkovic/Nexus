A note is formatted with markdown shortcuts and the commands menu opened by "/".

Shortcuts at the start of a line:

1. "# ", "## ", "### " — heading 1, 2 or 3.
2. "- " or "* " — a bullet list; "1. " — a numbered list; "> " — a quote; "```" — a code block.
3. "/" opens the block menu: headings, lists, a task list, a quote, a code block, a divider, the callouts ("Callout: note", "tip", "warning", "danger"), "Toggle section", "Table of contents", "Card (question :: answer)" and "Blank (cloze)".
4. "[[" makes a link to another note; the backlinks stand in the "Backlinks" panel.
5. Ctrl+Shift+C makes a blank (cloze) from the selected text. Ctrl+Z and Ctrl+Y undo and redo an edit.

Find inside a note: Ctrl+F opens the bar; "Enter" and "Shift+Enter" (or F3 and Shift+F3) walk the matches, "Esc" closes the bar and puts the cursor back on the match.

Cards from a note: a line with "Card (question :: answer)" or with blanks `{{…}}` makes study cards; in the "Cards" panel pick a "Card deck", because without one you read "Create a deck in the Study module so the cards from this note have somewhere to go." Earlier versions of a note are in "Version history" ("Restore this version").

Limits: markdown shortcuts can be turned off in Settings (the "Notes" card), but the "/" menu still works. An image goes into a note as an attachment ("Attach a file"), not as an outside link.
