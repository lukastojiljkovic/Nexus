Chess is a board game — against the engine or another person, with clocks, saved games and PGN.

How to use it: a new game is set up on the page (the opponent, the colour and the time control), and the game is played by clicking a piece and then a square. The move list sits beside the board, and a finished game is written into the archive by itself. "Saved games" holds the finished games with their result ("Review", "Delete"), and an unfinished one is shown as "Game in progress" with a "Continue the game" button.

Limits: the moves are written after every move, so a game continues after the page is closed; the clock itself is not saved — only the time control is, because a restored remaining time would claim that no time had passed. The "Against the engine" table counts "Games", "Won", "Drawn" and "Lost". Everything stays in the profile on this computer, and PGN comes out of a saved game.
