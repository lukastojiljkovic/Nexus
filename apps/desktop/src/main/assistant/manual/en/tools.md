Tools is a drawer of small calculations and conversions: units, percentage, VAT, loans and price per unit. No tool stores anything — each works from what you type.

How to use it:

1. In "Search tools…" type part of a tool's name; "Clear search" brings the whole list back.
2. The tools are grouped by category ("Conversion", "Calculation" and more). Pick one from the list; if the search matched nothing you read "No tool matches the search."
3. Type the values into the tool's fields; the result stands beside them and can be copied.

What Nexus does not convert: money. Currencies are tracked per account and never added across, because a rate an offline app cannot verify would be a number that quietly misstates money.

Limits: one preference, "Default VAT rate", only changes the value the field opens on; every calculation can be switched to another rate. It is changed in Settings, on the "Tools" card.
