Reference holds the Wikipedia, dictionaries and manuals you read without the internet, from ZIM files on this computer.

How to use it:

1. "Libraries" are the ZIM files that have been added: "Add a ZIM file" picks a file already on this computer, and an edition can also be downloaded from the Kiwix catalogue. Every library carries either "Verified download" or "Unverified file"; "Open" opens it, and "Remove" takes it off the list. A file that is no longer where it was says "The file is not where it was".
2. An article is shown in a frame that runs no script and cannot load anything but the pack itself.
3. "Title search" searches the beginning of the titles inside the chosen library, as you type. Full-text search is not available — the index inside a pack needs Xapian — so what is offered is what is possible: titles.
4. "Recently read" keeps what has been read and what is bookmarked, and the history can be cleared.

Everything is read from this computer, and a download goes only through the download service, and only for editions the catalogue offers. What was read and bookmarked is kept by the profile.
