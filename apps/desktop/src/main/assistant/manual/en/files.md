Files is one place for everything attached to notes, tasks and subjects. Nothing here is changed or deleted — the page only shows where each file is attached.

How to find a file:

1. In "Search by file name or owner…" type part of the name.
2. Narrow with the filters: "Where it is attached" ("All", "Notes", "Tasks", "Subjects") and "File type" ("Images", "PDF", "Text", "Other").
3. Switch between "List" and "Grid"; the columns are "Name", "Where", "Size" and "Added".
4. A file's menu ("⋮") holds "Preview", "Open", "Save as…" and "Go to…" — the last one opens the record that carries it.

Limits: the view stops at the 500 newest files, and then the total is a lower bound, which the "What takes up space" caption says. An attachment is removed from its own record (in the note, task or subject), not from here.
