Puzzles is four games on one page: "Sudoku", "Nonograms", "Mahjong" and "Numbers". Every game is saved and picks up exactly where it stopped.

How to use it: the tabs pick a puzzle; only the chosen one is mounted, and its game is re-read on every switch. The "Results" table shows the results of finished games and fills itself when one ends.

Limits: Settings, on the "Puzzles" card, turns on marking sudoku conflicts while the board is played. If a game cannot be saved, the page says so ("The game was not saved."). Everything remembered stays in the profile, on this computer.
