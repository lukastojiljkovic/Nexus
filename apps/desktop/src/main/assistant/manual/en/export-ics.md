The calendar export makes one .ics file of your events — the standard format Google Calendar, Apple Calendar and Outlook open.

How to export:

1. Under "Import and export" open "Calendar export".
2. Click "Export calendar (.ics)" and pick where the file is saved.

Limits: the file is not password-protected, because then no other calendar could open it — the card says so too. This export carries the calendar only; the whole profile is exported with "Export all data…" on the "Backup and restore" card.
