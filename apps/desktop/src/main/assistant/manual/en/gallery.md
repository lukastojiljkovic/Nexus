The Gallery brings three sources into one grid: images from installed art packs, images from downloaded Reference libraries, and your own pictures.

How to use it:

1. "Add your images" opens the system file picker. Nexus decodes the selected image in main, creates a small encrypted thumbnail and stores both the thumbnail and original as encrypted profile data.
2. "Search the gallery", "Source" and "Tag" combine with one another. Personal images can also be renamed, tagged and given notes.
3. "Load images from Reference" scans a downloaded library in bounded pages. These images stay read-only and are served from the library rather than copied into your profile.
4. Selecting a card opens the full image. Pack and Reference images show their credit and licence or library attribution.
5. Deleting a personal image asks for confirmation and removes both encrypted blobs when no other record uses them.

The Gallery never exposes a file path, ZIM path or encryption key to the page. Private Notes remains a separate locked module and is never included in Gallery.
