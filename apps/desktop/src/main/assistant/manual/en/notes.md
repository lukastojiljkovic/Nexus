Notes is a block editor: you write text and format it with markdown shortcuts or the menu opened by "/". The list is on the left ("List" or "Cards"), the editor on the right.

How to make a note:

1. Click "New note" above the list.
2. Type the title in the first line; until you do, the note is called "Untitled".
3. Write in the editor, where the placeholder says "Start writing, or type "/" for commands…".

Order comes from three axes: folders ("New folder", "New subfolder"), tags ("New tag") and categories ("New category"). A tag says what a note is about, a category what kind it is, a folder where it lives. The note's menu ("More options") holds "Pin", "Move to folder" and "Duplicate"; attachments go through "Attach a file" and earlier versions through "Version history".

Limits: deleting a folder, a tag or a category asks you to type its name; a deleted note can be undone only until you lock the app.
