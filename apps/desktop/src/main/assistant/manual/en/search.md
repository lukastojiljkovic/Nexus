Search is one window for everything: it finds tasks, notes, events, documents, cards and circuits, and runs commands. It opens with the "Command palette" shortcut (Ctrl+K by default) or the "Search" row in the app menu.

How to use it:

1. Type part of a word in "Search tasks, notes, events…".
2. The groups are "Recent", "Commands", "Quick actions" and "Recent searches"; the type filter sits beside the field.
3. The grammar: "#tag" filters by tag, and "due:today / tomorrow / week / 2026-08-15" by date. Move with the arrows, "Enter" opens, "Esc" closes.
4. "Show all results" hands the query to the full "Search" page.

Commands in the palette include "New task", "New event", "New note", "New transaction", the "Tasks: …" rows for the views, "Switch theme", "Lock the app" and "Rebuild the search index".

Limits: private notes never appear in search. The full page shows the first 500 results and then reads "The first 500 results are shown — narrow the search for a more precise list." Search history is kept in the profile (the last 20 queries) and deleted in Settings, on the "Data and privacy" card.
